3. Observation

The execution times vary depending on the number of processes and the
MPI collective operation. In these tests, the measured execution time
also depends on the local WSL system and CPU scheduling.

The Bcast approach involves broadcasting the complete array to every
process, which results in more data being communicated.

Scatter distributes only the required chunk to each process.

Gather collects the partial sums at the root, while Reduce combines
the partial sums directly using MPI_SUM.

Allreduce provides the combined result to every process.

Scan produces a prefix result for each process rather than the same
global result for all processes.


4. Thinking Question

When would you choose MPI_Scan over MPI_Allreduce?

MPI_Scan should be used when each process needs a cumulative result
from rank 0 through its own rank. MPI_Allreduce should be used when
every process needs the same global reduction result.

For example, MPI_Scan can be used to calculate cumulative offsets for
parallel data processing. Each process can use its sum_before_me value
as an offset when assigning global positions to its local data.
